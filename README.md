# RecRoom3DS

Мини-игра «песочница в комнате» от первого лица для **старой 3DS / 2DS**, собранная на C2D (soft-3D: кубы рисуются как цветные прямоугольники с сортировкой по глубине и перспективой).

Автор проекта — **Глеб**, оформление и сборка — MultiTool.

## Что умеет

- Полноценное первое лицо: ходьба, поворот, наклон взгляда.
- Две независимые руки:
  - **зажми L** — левая рука следует за стиком (движение в горизонтальной плоскости + вверх/вниз крестовиной);
  - **зажми R** — правая рука следует за стиком;
  - **X** — захватить предмет, на который указывает рука; ещё раз **X** — отпустить.
- Комната с полом-сеткой и кубами, которые можно хватать руками и переносить.
- Верхний экран — вид от первого лица, нижний — индикация режимов рук.

## Управление (старая 3DS / 2DS)

| Кнопка | Действие |
|---|---|
| Стик | ходьба (когда руки не задействованы) |
| Крестовина | поворот (←/→), наклон (↑/↓) в режиме ходьбы |
| **L + стик** | движение **левой** руки |
| **R + стик** | движение **правой** руки |
| **X** | захватить / отпустить предмет выбранной рукой |
| START | выход в hbmenu |

Когда зажата L или R, стик двигает руку, а крестовина ↑/↓ — поднимает/опускает её.

## Как собрать

Сборка через **GitHub Actions** (нужен репозиторий на GitHub):

1. Положи эти файлы в репозиторий (вместе с папками `source/`).
2. Открой вкладку **Actions** — workflow `build` запустится сам на каждой заливке (push) или вручную (кнопка *Run workflow*).
3. После сборки внизу списка запусков будет артефакт **recroom3ds-3dsx** — это архив с `recroom3ds.3dsx`.
4. Скачай его и положи `recroom3ds.3dsx` на SD-карту в `/3ds/`, затем запусти через Homebrew Launcher.

### Сборка локально (по желанию)

Нужен devkitPro с пакетом `3ds-dev`:

```
make -j$(nproc)
```

Результат: `recroom3ds.3dsx`, `recroom3ds.elf`, `recroom3ds.smdh`.

## Структура

```
source/main.c        — вся игра: 3D-математика, ввод, рендер
Makefile             — официальный шаблон devkitPro (citro2d/citro3d)
.github/workflows    — сборка в GitHub Actions
```
